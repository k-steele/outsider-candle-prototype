# Outsider Candle Company prototype

A throwaway visual prototype for the question: **How should the first Shopify storefront express Outsider Candle Company’s modern-prairie-nostalgia brand direction?**

Run it with one command from this folder:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`. Use the floating page switcher to review Home, Shop, Product, and Story.

This is intentionally not a production Shopify theme. It is a direction-setting artifact before implementation.
